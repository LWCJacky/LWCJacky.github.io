# 顏色感測器 TCS3200

參考資料連結 (opens new window)

# 工作原理

S2/S3腳位輸入不同的0/1組合 能後觸發不同的的濾波器過濾顏色

  • L/L會只有紅色能通過
  • L/H只有藍色可以通過
  • H/L所有顏色都可以通過（可以用來判斷顏色的深淺）
  • H/H只有綠色可以通過
